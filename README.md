## 👨‍💻 Sobre mim

Olá! Sou **Henrique Martins Pereira**, estudante de Análise de Dados e entusiasta da tecnologia.

Atualmente, estou desenvolvendo minhas habilidades em programação, bancos de dados e análise de informações, com o objetivo de transformar dados brutos em insights relevantes para a tomada de decisões.

Tenho interesse em trabalhar com dados, identificar padrões, desenvolver consultas e construir projetos que simulem situações reais do mercado.

Meu foco atual está em:

- 🐍 **Python:** programação e manipulação de dados.
- 🗄️ **SQL:** consultas, agregações e relacionamentos entre tabelas.
- 🌐 **Requests:** consumo básico de APIs e extração de dados.

Acredito que a evolução profissional acontece por meio da prática, da curiosidade e da construção constante de novos projetos.

### 🟡 Pokémon Data Pipeline

Projeto desenvolvido utilizando Python e PokéAPI, com foco na construção de um pipeline de dados.

**Principais etapas:**

- Extração de informações através de uma API REST.
- Consumo e manipulação de dados JSON.
- Organização e tratamento das informações.
- Armazenamento dos dados em banco SQLite.

**Tecnologias utilizadas:**

`Python` `Requests` `PokéAPI` `SQLite`
